2. Implemented Core Components

A. Core AI Review Engine (src/aiCodeReviewer.js)

  • Strict Code-Only Scope: System prompt strictly constrains Gemini to review only code diffs and modified files. Ignores business logic and non-code docs.
  • Structured JSON Output Schema:
    • verdict: 'APPROVED' | 'CHANGES_REQUESTED' | 'COMMENT'
    • overallScore: Integer 0 - 10
    • summary: Concise executive assessment
    • highlights: Positive aspects, design strengths
    • securityAdvisories: Array of { severity, title, description, cweOrOwasp }
    • inlineComments: Array of { filePath, line, category, severity, comment, suggestedFix }
  • Salesforce & Security Rules: Enforces Apex Governor Limits (no SOQL/DML in loops), with sharing keywords, hardcoded secrets detection, and XML schema validity.

B. GitHub PR Client (src/githubPrClient.js)

  • Intelligent File Filtering: Strips binaries, lockfiles (package-lock.json), and assets to prevent context bloat and focus exclusively on executable source.
  • Line & Hunk Mapper: Translates unified diff line positions into GitHub review comment line coordinates.
  • Author Self-Review Fallback: Overcomes GitHub's restriction where bot tokens cannot approve their own PRs by gracefully falling back to a structured review comment badge.

C. Main Pipeline Integration (orchestrator.js)

  • Directly wired into Phase 5 (runPrReviewWorkflow) of the multi-agent pipeline.
  • Persists persistent audit artifacts to agent-context/tickets/<KEY>/pr-review.md.
  • Gates progression to QA Testing until Gemini yields an APPROVED verdict.

4. Autonomous Self-Healing Loop ("Apply AI Fixes")

When code issues or vulnerabilities are found, clicking [ 🛠️ Apply AI Fixes ] triggers an autonomous recovery flow:

  1. Extract Findings: Gathers recommendations and line-level fixes from the review report.
  2. Prompt Builder (Agent 2): Injects the required fixes into buildAgent2PrReviewFixPrompt.
  3. Target Org Validation: Agent 2 patches code and executes: 
    sf project deploy start --target-org time-sheet
  4. Git Commit & Push: Commits to portal/<TICKET-KEY> and pushes directly to GitHub.
  5. Automated Re-Review: Re-runs Gemini code review to confirm that the score increases and all blockers are resolved.

5. GitHub Actions CI/CD Integration

File: .github/workflows/pr-code-review.yml

  • Trigger Events: pull_request (opened, synchronize, reopened, ready_for_review) and workflow_dispatch.
  • Concurrency Management: Automatically cancels obsolete in-flight runs when new commits arrive.
  • Job Summaries: Generates GitHub Actions Step Summaries containing review scorecards and findings.
  • Central Switch: Dynamically toggled via switchManager.js to balance local agent runs and GitHub Actions CI.

6. Resilience, Quota & Multi-Model Failover
